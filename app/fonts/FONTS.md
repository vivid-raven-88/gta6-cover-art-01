# Fonts

The cover maker letters its captions with two open fonts, both shipped as
files under this directory and loaded by `app/style.css` with `@font-face`.
Nothing is fetched from a font service at run time.

## Anton Regular

- File: `Anton-Regular.ttf`
- Designer: Vernon Adams (revised by Jacques Le Bailly)
- License: SIL Open Font License 1.1 (see `OFL.txt`)
- Source: https://github.com/google/fonts/tree/main/ofl/anton
- Used for: the big cover title and the editor headings.

## Pacifico Regular

- File: `Pacifico-Regular.ttf`
- Designer: Vernon Adams
- License: SIL Open Font License 1.1 (see `OFL.txt`)
- Source: https://github.com/google/fonts/tree/main/ofl/pacifico
- Used for: the script subtitle under the cover title.

Neither font is a Rockstar Games font, and neither file is taken from any game.
